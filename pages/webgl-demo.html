📖 Usage Guide

The WebGL Transition System is designed to be simple and lightweight. Include the script and Three.js library, then initialize with a single line of code.

<!-- Include Three.js library -->
<script src="https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.min.js"></script>

<!-- Include WebGL Transition System -->
<script src="js/webgl-transition-system.js"></script>

<script>
  // Create and initialize the system
  const transitionSystem = new WebGLTransitionSystem('container-id');
  transitionSystem.init();

  // Optional: Add rotation for visual effect
  transitionSystem.rotateParticles(0.001, 0.002, 0.001);

  // Clean up when done
  transitionSystem.destroy();
</script>

Configuration: The system uses sensible defaults, but you can modify the CONFIG object in webgl-transition-system.js to customize particle count, size, colors, and camera position.

🔧 Technical Details

• Particle Count: 1000 particles
• Geometry: BufferGeometry for efficient rendering
• Material: PointsMaterial with vertex colors
• Space Range: 20 units (±10 on each axis)
• Camera: Perspective camera with 75° FOV
• Background: Pure black (0x000000)
• Rendering: WebGL with antialiasing enabled
• Performance: Hardware-accelerated GPU rendering

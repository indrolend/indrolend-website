💡 How It Works

  • 1000 Particles: Rendered using Three.js BufferGeometry
  • Dispersion Effect: Particles explode outward from center
  • Fade Out: Smooth opacity transition
  • Auto-Navigation: Page loads after animation completes
  • Hardware Accelerated: Uses WebGL for smooth performance

🔧 Integration Code

Add this to any page to enable WebGL transitions:

<!-- Include Three.js -->
<script src="https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.min.js"></script>

<!-- Include WebGL Transition System -->
<script src="../js/webgl-transition-system.js"></script>

<script>
  // Initialize page transitions
  document.addEventListener('DOMContentLoaded', () => {
    WebGLPageTransitions.init({
      enabled: true
    });
  });
</script>

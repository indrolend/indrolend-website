2. Manual Transition Control

Trigger transitions programmatically with custom settings:

Code Example:

// Get API instance
const api = window.HybridPageTransitionAPI.instance;

// Start custom transition
api.startTransition({
  fromElements: document.querySelectorAll('h1, h2'),
  colors: ['rgba(255, 0, 0, 0.9)', 'rgba(0, 255, 0, 0.9)'],
  particleCount: 200,
  explosionIntensity: 1.5,
  onComplete: () => {
    console.log('Transition complete!');
  }
});

4. Runtime Configuration

Update configuration on the fly:

Code Example:

// Update particle count
api.updateConfig({ particleCount: 150 });

// Toggle auto-optimization
api.updateConfig({ autoOptimize: true });

// Add page-specific behavior
window.HybridPageTransitionConfig.addPageBehavior('custom', {
  particleCount: 200,
  explosionIntensity: 1.5,
  colors: ['rgba(255, 0, 0, 0.9)']
});

6. CSS Fallback for Non-WebGL Devices

For devices without WebGL support, the API automatically falls back to Canvas 2D or CSS transitions:

Code Example:

// Manually trigger CSS fallback
window.HybridPageTransitionAPI.CSSFallback.applyTransition(() => {
  window.location.href = 'next-page.html';
});
